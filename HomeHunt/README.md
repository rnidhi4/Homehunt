# HomeHunt - Property Discovery and Rental Platform (Frontend)

React + Vite frontend. No backend: all data is stored in the browser's LocalStorage.

## Run
1. Install Node.js (v18 or newer) and extract this ZIP.
2. Open the `HomeHunt` folder in VS Code, then open a terminal (Ctrl + `).
3. Run `npm install`, then `npm run dev`.
4. Open the shown link (http://localhost:5173).
